# ترحيل بيانات عميلة من شوبيفاي إلى Codera

الهدف: نقل كتالوج منتجات أي متجر شوبيفاي إلى منصّة Codera، بحيث يكمل المتجر عمله على
**دومينه الخاص** داخل Codera (بدون الاعتماد على شوبيفاي).

يوجد مساران — كلاهما مبنيّان في `src/services/shopify/importer.js` ومتاحان من
لوحة التاجر → **استيراد شوبيفاي**.

---

## المسار الأول: عبر واجهة شوبيفاي (API) — موصى به

يسحب المنتجات مباشرة (العنوان، الوصف، السعر، الصور، النوع/الوسوم).

### خطوات الحصول على التوكن (من متجر العميلة)
1. لوحة شوبيفاي → **Settings → Apps and sales channels → Develop apps**.
2. **Create an app** → سمّيه مثلاً `Codera Import`.
3. **Configuration → Admin API integration** → فعّل الصلاحيات:
   - `read_products`
   - `read_product_listings` (اختياري)
4. **Install app** ثم انسخ **Admin API access token** (يبدأ بـ `shpat_...`).
5. في لوحة Codera: أدخِلي `store.myshopify.com` والتوكن → **استيراد المنتجات**.

> الاستيراد يحفظ الربط في `shopify_connections` لإعادة المزامنة لاحقاً.

### تقنياً
```
GET https://{shop}/admin/api/2024-10/products.json?limit=250
Header: X-Shopify-Access-Token: shpat_...
```
لأكثر من 250 منتجاً: استخدم ترقيم الصفحات عبر رابط `Link` (page_info) — إضافة بسيطة في
`importFromShopifyApi`.

---

## المسار الثاني: عبر ملف CSV (بدون صلاحيات)

مناسب إذا لم تتوفّر صلاحيات API.

1. لوحة شوبيفاي → **Products → Export → All products → CSV for Excel**.
2. في لوحة Codera: **استيراد شوبيفاي → عبر ملف CSV** → ارفعي الملف.

المحلّل يجمع صفوف المنتج الواحد حسب عمود `Handle` (شوبيفاي يكرّر الـ Handle للصور/المتغيّرات)
ويأخذ: `Title`, `Body (HTML)`, `Variant Price`, `Type`, `Tags`, `Image Src`.

---

## ماذا يُنقل الآن vs لاحقاً

| العنصر | الحالة |
|---|---|
| المنتجات (عنوان، وصف، سعر، صور، فئة) | ✅ مبني |
| تصنيف الفئة تلقائياً (عباية/فستان/علوي/سفلي/إكسسوار) | ✅ مبني |
| الطلبات والعملاء | 🔜 (Orders/Customers API — إضافة لاحقة) |
| المخزون والمتغيّرات (مقاسات/ألوان) | 🔜 |
| مزامنة دورية تلقائية | 🔜 (webhook/cron) |

---

## بعد الاستيراد

1. راجعي فئات المنتجات (تؤثّر على دقّة التجربة الافتراضية).
2. تأكّدي أن **صورة القطعة** واضحة (flat-lay أو خلفية بسيطة) لأفضل نتيجة توليد.
3. فعّلي الموديلات المناسبة لجمهور المتجر (مع/بدون حجاب).
4. اربطي الدومين الخاص من **الإعدادات والدومين**.
