# خارطة الطريق — من الـ MVP إلى الإطلاق

## ✅ المرحلة 0 — الأساس (منجز في هذا المستودع)
- منصّة multi-tenant وايت-ليبل + توجيه حسب الدومين/النطاق الفرعي.
- لوحة التاجر (منتجات، موديلات، استيراد، اشتراك، دومين، إعدادات).
- واجهة الزوّار + التجربة الافتراضية (اختيار موديل، حجاب، وضعية، رفع صورة العميلة).
- طبقة AI قابلة للتبديل (Mock/FASHN/Replicate) + طابور وظائف واستعلام حالة.
- استيراد شوبيفاي (API + CSV) + تصنيف الفئات.
- اشتراكات بحصص + تتبّع استهلاك + محوّل UPayment + دفع تجريبي.
- لوحة المنصّة (مؤشرات + MRR) + ودجت تضمين.

## 🔜 المرحلة 1 — جاهزية الإنتاج (2–3 أسابيع)
- **ربط مزوّد AI حقيقي** (FASHN موصى به) + مفاتيح + مراقبة تكلفة/توليدة.
- نقل الحالة إلى **PostgreSQL** + تخزين الصور على **S3/R2/Cloudflare**.
- **طابور حقيقي** (Redis/BullMQ) مع إعادة محاولة ومعالجة متوازية.
- **الدومينات الخاصة** آلياً عبر Caddy On-Demand TLS.
- تحديد معدّل، تحقّق من الصور، سجلّات وأخطاء.

## 🔜 المرحلة 2 — قوة المنتج (3–4 أسابيع)
- **موديلات ثابتة الهوية** لكل شخصية (reference/seed ثابت أو LoRA) لاتساق الوجه.
- تحكّم أدق: خلفيات، إضاءة، مقاسات، ألوان متعددة للقطعة.
- استيراد شوبيفاي المتقدّم: صفحات >250، متغيّرات، مزامنة دورية، Orders/Customers.
- الدفع المتكرر التلقائي (cron) + تنبيهات فشل الدفع + فواتير.
- تحليلات للتاجر: أكثر القطع تجربةً، تحويل التجربة → شراء.

## 🔜 المرحلة 3 — النمو (مستمر)
- **تطبيق شوبيفاي مدمج** رسمي (لمن يريد البقاء على شوبيفاي) + Shopify Billing.
- لوحة شركاء/وكلاء لإعادة البيع.
- توليد **فيديو** قصير للقطعة على الموديل.
- مكتبة موديلات موسّعة + رفع موديل خاص بالتاجر.
- تعدّد اللغات (عربي/إنجليزي) وأسواق إضافية.
