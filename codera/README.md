# Codera — منصّة تجربة اللبس الافتراضية بالذكاء الاصطناعي (SaaS · وايت-ليبل)

منصّة متكاملة تبيعينها للمتاجر كاشتراك شهري. كل متجر (تاجر) = **مستأجر مستقل** يعمل
على **دومينه الخاص** بدون ظهور اسم شركتك. التاجر يرفع صور قطع الملابس/الإكسسوارات،
والنظام يولّد صوراً احترافية لموديل يلبسها — بموديلات خاصة بـ Codera، مع خيار **الحجاب**،
أو على **صورة العميلة** نفسها.

شوبيفاي ليس شرطاً — هو فقط **مصدر بيانات** ننقل منه كتالوج أي عميلة إلى Codera.

---

## المكوّنات

| المكوّن | الوصف | المسار |
|---|---|---|
| الصفحة التعريفية | تسويق المنصّة + الباقات | `/` |
| **لوحة التاجر** | إدارة المنتجات، الموديلات، الاستيراد، الاشتراك، الدومين | `/dashboard` |
| **واجهة الزوّار** (المتجر) | تصفّح المنتجات + التجربة الافتراضية | `/store` أو دومين المتجر |
| ودجت التضمين | زر «جرّبيها» يُضاف لأي موقع/شوبيفاي | `/widget.js` |
| لوحة المنصّة | مؤشرات كل المتاجر + الإيراد الشهري | `/admin` |

## التشغيل

```bash
cd codera
npm run seed     # ينشئ قاعدة البيانات + بيانات تجريبية
npm start        # يشغّل الخادم على :3000
```

> يعمل بدون أي مكتبات خارجية — Node.js ‏22.5+‎ فقط (يستخدم `node:sqlite` المدمج).

### حسابات تجريبية

- **تاجر:** `demo@noor.sa` / `demo1234` → `/dashboard`
- **منصّة:** `admin@codera.app` / `admin1234` → `/admin`
- **متجر تجريبي:** `/store?tenant=noor`

## الإعداد (`.env`)

انسخي `.env.example` إلى `.env`. أهم المفاتيح:

- `AI_PROVIDER` = `mock` (افتراضي، بدون مفاتيح) · أو `fashn` · أو `replicate`
- `BASE_DOMAIN` = دومين النطاقات الفرعية (مثال: `codera.app`)
- `UPAYMENT_*` = مفاتيح بوابة الدفع (اختياري؛ بدونها يعمل دفع تجريبي)

## بنية المشروع

```
codera/
├── src/
│   ├── server.js            # الخادم + توجيه المستأجرين
│   ├── db/                  # المخطط + التهيئة + البذور
│   ├── lib/                 # config, http, auth, tenant, crypto, svg
│   ├── routes/              # auth, dashboard, storefront, billing, admin
│   └── services/
│       ├── ai/              # طبقة الذكاء الاصطناعي القابلة للتبديل
│       ├── shopify/         # استيراد المنتجات (API + CSV)
│       └── billing/         # الخطط + الحصص + UPayment
├── public/                  # الواجهات (landing, dashboard, storefront, admin, widget)
└── docs/                    # الخطة، التسعير، ترحيل شوبيفاي، خارطة الطريق
```
