# NIST CSF quick reference

- **Identify** — asset inventory, risk assessment, governance.
- **Protect** — access control, awareness training, data security.
- **Detect** — monitoring, logging, anomaly detection.
- **Respond** — incident response plan, communications.
- **Recover** — backups, recovery planning, lessons learned.
